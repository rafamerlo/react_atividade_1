# Desafio 01 - Produto em React

##  Descrição

Este projeto foi desenvolvido em React com o objetivo de criar uma página simples para exibir informações de um produto.

O produto escolhido foi o **Dior Addict Lip Maximizer**, um gloss labial da marca Dior.

## 💄 Informações do Produto

* **Nome:** Dior Addict Lip Maximizer
* **Marca:** Dior
* **Descrição:** Gloss labial com brilho intenso e efeito hidratante.
* **Preço:** R$ 249,90

##  Tecnologias utilizadas

* React
* JavaScript
* HTML
* CSS
* VS Code

##  Objetivo

Praticar a criação de componentes em React, utilizando variáveis para armazenar informações e exibindo esses dados na tela através do JSX.

## ▶ Como executar

1. Instale as dependências do projeto:

```bash
npm install
```

2. Execute o projeto:

```bash
npm run dev
```

3. Acesse o endereço exibido no terminal para visualizar a aplicação.
